## ⚙️ Instalação e execução

### Pré-requisitos

- Node.js numa versão compatível com o projecto.
- npm ou outro gestor de pacotes compatível.
- Git, opcional para controlo de versões.

### 1. Clonar o repositório

Substitui `URL_DO_REPOSITORIO` pelo endereço real do teu repositório Git.

```bash
git clone URL_DO_REPOSITORIO
cd portfolio
```

### 2. Instalar dependências

```bash
npm install
```

### 3. Executar em desenvolvimento

```bash
npm run dev
```

Abre no navegador o endereço local indicado pelo Vite, normalmente `http://localhost:5173`.

### 4. Criar a versão de produção

```bash
npm run build
```

### 5. Testar a versão de produção localmente

```bash
npm run preview
```

Os comandos dependem dos scripts definidos no `package.json`.
